🚇 METRO ALARM - APP ICON REPLACEMENT PLACEHOLDER
========================================================================

How to replace the app icon:

1. Copy your custom icon image (PNG, JPG, or WEBP - recommended size: 512x512 or 1024x1024).
2. Paste it in this folder (`assets/icon/`) replacing `PASTE_YOUR_ICON_HERE.png`, or save it as `app-icon.png` or `icon.png`.
3. Double-click `update-icon.bat` in the project root folder (or run `python tools/generate-icons.py`).

What happens automatically:
- Resizes and updates all Android launcher icons (standard + circular for all densities: mdpi, hdpi, xhdpi, xxhdpi, xxxhdpi).
- Resizes and updates all iOS icons in Images.xcassets.
- Updates the in-app header logo and splash screen hero image.
